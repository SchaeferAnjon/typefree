RAG 是什么意思？

RAG 就是「检索增强生成」：先从资料里找出和问题相关的内容，再交给大模型组织成回答。回答有依据，资料更新了也不用重新训练模型。

按住回答 · 接着问

句尾说「用英文」，这句就是英文。口令由程序规则识别，不靠模型猜。也可以在「探索」页固定一种输出语言，不用每次都说。

明天下午三点开会，记得带上电脑，用英文用日文用韩文

常见问题

和系统自带的听写有什么区别？
系统听写更像逐字转录，「嗯、那个」也会照打。Typefree 会在识别后整理语言——去口水词、理顺句子、规范数字和标点，让输出可以直接发送，或者直接当作给 AI 的指令。
Typefree 是开源的吗？
是。Mac 版代码以 GPL-3.0 协议公开在 GitHub，每一步数据去了哪里都能自己核对，也可以自己编译使用（自己编译的版本需要填自己的 API Key）。「Typefree」名称和图标不在开源授权范围内。
怎么收费？可以先免费试用吗？
可以。新用户有 7 天免费试用，零配置、费用由我们承担（7 天共 10,000 字）。之后两种选择：填入你自己的 API Key，永久免费、不限字数；或开通会员（¥188/年），不用配置任何 Key。详见 价格。
支持哪些服务商和模型？
识别用火山引擎；润色用通义千问，模型按质量或速度自动选，也可以选「不优化」，直接输出识别原文。
它是完全离线的吗？
不是。识别和整理需要调用云端的语音识别和大模型服务。Typefree 强调的是本地优先、代码开源、数据去向透明，而不是「断网也能用」。
需要注册账号吗？
不需要。Typefree 没有账号系统：下载打开就能说，试用不用填任何信息。开通会员时，付款页填一个邮箱用来接收授权码，把授权码填进 App 就行。有问题可以在 App 的「反馈」页直接说，也不用登录、不用留邮箱。
不太会配 API 的人能用吗？
能。开通会员就不用配置任何 Key，装好就能说话；想自己配，也有 5 分钟图文教程。
我的录音和数据安全吗？
历史记录加密保存在你自己的 Mac 上（~/.config/voicepolish/），API Key 存在系统钥匙串里。用自己的 Key 时，请求只发往你配置的服务商，不经过我们；免费试用和会员期间，经我们的服务器转发，只转发、不保存录音和文字。
