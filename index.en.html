without letting go of the mouse.

Hold the mouse to talk. Don’t want to remember a hotkey? Hold the mouse in any text field for about half a second and start talking. Need to let go mid-sentence? Drag down a little to lock, then click ✓ when you’re done. Changed your mind? Drag far away and let go when it glows red.

See something unclear? Hold and ask. No window switching, no copying. Hold the mouse on empty space and ask; the answer appears in the top-right corner. Hold the answer to follow up, or pin it to keep it.

What does RAG mean?

RAG stands for Retrieval-Augmented Generation: first find the passages relevant to the question, then let the model compose an answer from them. Answers are grounded, and updating the documents needs no retraining.

FAQ

How is this different from built-in dictation?
System dictation is closer to word-for-word transcription — it types out every “um” and “you know.” Typefree cleans up the language after recognition — removing fillers, smoothing sentences, normalizing numbers and punctuation — so the output is ready to send or to use as a prompt.
Is Typefree open source?
Yes. The Mac app’s code is public on GitHub under GPL-3.0, so you can check where your data goes at every step, or build it yourself (self-built copies need your own API keys). The Typefree name and icon are not covered by the open-source license.
How much does it cost? Can I try it first?
Yes. New users get a free 7-day trial — zero setup, on us, 10,000 characters in total. After that, use your own API key free forever with no limits, or become a member ($26/year) and skip the setup. See Pricing.
Which providers and models are supported?
Recognition uses Volcengine; clean-up uses Qwen, with the model picked automatically for quality or speed — or choose “No polish” to get the raw transcript.
Does it work offline?
No. Recognition and clean-up call cloud speech-recognition and LLM services. Typefree’s promise is local-first storage, open source and transparent data routing — not “works without internet.”
Do I need an account?
No. Typefree has no account system: download it, open it and talk — the trial needs no details at all. When you become a member, checkout asks for an email to deliver your license key; paste the key into the app and you’re done. Questions? Use the Feedback page in the app — no login, no email needed.
I’m not great with APIs — can I still use it?
Yes. As a member you don’t need any API keys — install and start talking. If you’d rather set up your own, there’s a 5-minute illustrated guide.
Are my recordings and data safe?
History is stored encrypted on your Mac (~/.config/voicepolish/), and API keys are kept in the system Keychain. With your own key, requests go only to the providers you configured, never through us; during the free trial and membership, they’re relayed by our server — relayed only, audio and text are never stored.
