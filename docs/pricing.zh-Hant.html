關於付費的問題

開會員要註冊帳號嗎？
不用。付款時填一個信箱接收授權碼，把授權碼填進 App 就開通了。Typefree 沒有帳號系統，也不需要手機號碼。
試用到期後會怎樣？
開通會員就能繼續用；也可以在「設定 → 模型」填入你自己的 API Key，永久免費、不限字數。
銀行卡和微信付款有什麼不同？
銀行卡開通是每年自動續費，隨時可以取消；微信付款是一次性買一年，不會自動扣費。
付款後授權碼在哪？
約 5 分鐘內會自動發到你付款時填寫的信箱，記得翻一下垃圾郵件匣，請不要重複付款。授權碼丟了，可以在 找回授權碼 頁面找回。
自帶 Key 要花多少錢？
由火山引擎和通義千問按你的實際用量計費，直接走你自己的帳戶，我們不經手、不加價。
自己從原始碼編譯的版本能用試用和會員嗎？
不能。試用和會員通道只在官方簽名版（官網或 GitHub Releases 下載的安裝檔）裡可用。自己編譯的版本填入自己的 Key 即可，功能完全一樣。
一個會員能用幾台 Mac？
一個授權碼用於 1 台 Mac。
怎麼取消自動續費？
回覆購買確認信，或寄信到 ray@typefree.app 即可。取消後本期到期不再扣款，已付費的本期照常使用。
可以退款嗎？
可以。首次開通會員後 7 天內，不滿意可以申請全額退款，無需理由；自動續費扣款後 7 天內，也可以申請退還本期費用。怎麼申請見 退款政策。
