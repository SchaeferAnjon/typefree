关于付费的问题

开会员要注册账号吗？
不用。付款时填一个邮箱接收授权码，把授权码填进 App 就开通了。Typefree 没有账号系统，也不需要手机号。
试用到期后会怎样？
开通会员就能继续用；也可以在「设置 → 模型」填入你自己的 API Key，永久免费、不限字数。
银行卡和微信付款有什么不同？
银行卡开通是每年自动续费，随时可以取消；微信付款是一次性买一年，不会自动扣费。
付款后授权码在哪？
约 5 分钟内会自动发到你付款时填写的邮箱，记得翻一下垃圾箱，请不要重复付款。授权码丢了，可以在 找回授权码 页面找回。
自带 Key 要花多少钱？
由火山引擎和通义千问按你的实际用量计费，直接走你自己的账户，我们不经手、不加价。
自己从源码编译的版本能用试用和会员吗？
不能。试用和会员通道只在官方签名版（官网或 GitHub Releases 下载的安装包）里可用。自己编译的版本填入自己的 Key 即可，功能完全一样。
一个会员能用几台 Mac？
一个授权码用于 1 台 Mac。
怎么取消自动续费？
回复购买确认邮件，或发邮件到 ray@typefree.app 即可。取消后本期到期不再扣款，已付费的本期照常使用。
可以退款吗？
可以。首次开通会员后 7 天内，不满意可以申请全额退款，无需理由；自动续费扣款后 7 天内，也可以申请退还本期费用。怎么申请见 退款政策。
