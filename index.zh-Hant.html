RAG 是什麼意思？

RAG 就是「檢索增強生成」：先從資料裡找出和問題相關的內容，再交給大模型組織成回答。回答有依據，資料更新了也不用重新訓練模型。

按住回答 · 接著問

句尾說「用英文」，這句就是英文。口令由程式規則辨識，不靠模型猜。也可以在「探索」頁固定一種輸出語言，不用每次都說。

常見問題

和系統自帶的聽寫有什麼區別？
系統聽寫更像逐字轉錄，「嗯、那個」也會照打。Typefree 會在辨識後整理語言——去口水詞、理順句子、規範數字和標點，讓輸出可以直接發送，或者直接當作給 AI 的指令。
Typefree 是開源的嗎？
是。Mac 版程式碼以 GPL-3.0 授權公開在 GitHub，每一步資料去了哪裡都能自己核對，也可以自己編譯使用（自己編譯的版本需要填自己的 API Key）。「Typefree」名稱和圖示不在開源授權範圍內。
怎麼收費？可以先免費試用嗎？
可以。新使用者有 7 天免費試用，免設定、費用由我們承擔（7 天共 10,000 字）。之後兩種選擇：填入你自己的 API Key，永久免費、不限字數；或開通會員（¥188/年），不用設定任何 Key。詳見 價格。
支援哪些服務商和模型？
辨識用火山引擎；潤色用通義千問，模型按品質或速度自動選，也可以選「不優化」，直接輸出辨識原文。
它是完全離線的嗎？
不是。辨識和整理需要呼叫雲端的語音辨識和大模型服務。Typefree 強調的是本地優先、程式碼開源、資料去向透明，而不是「斷網也能用」。
需要註冊帳號嗎？
不需要。Typefree 沒有帳號系統：下載開啟就能說，試用不用填任何資訊。開通會員時，付款頁填一個信箱用來接收授權碼，把授權碼填進 App 就行。有問題可以在 App 的「回饋」頁直接說，也不用登入、不用留信箱。
不太會設定 API 的人能用嗎？
能。開通會員就不用設定任何 Key，裝好就能說話；想自己設定，也有 5 分鐘圖文教程。
我的錄音和資料安全嗎？
歷史記錄加密保存在你自己的 Mac 上（~/.config/voicepolish/），API Key 存在系統鑰匙圈裡。用自己的 Key 時，請求只發往你設定的服務商，不經過我們；免費試用和會員期間，經我們的伺服器轉發，只轉發、不保存錄音和文字。
